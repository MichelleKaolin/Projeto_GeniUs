## 3. GeniUs## 📚 GeniUs Project## 📌 Overview
GeniUs is a gamified study application that uses Artificial Intelligence to create personalized daily challenges and promotes competitions among university students. The goal is to increase study engagement in an interactive and fun way.
## 🎯 Objectives

* Personalize learning with AI.
* Create healthy competition among students.
* Use gamification to encourage a study routine.
* Ensure a fair environment by preventing fraud.

## 🎯 Target Audience
University students who want to improve their academic performance in a dynamic and motivating way.
## 🚀 Features

* 📌 User registration and login.
* 📌 Subject selection to personalize learning.
* 📌 AI-generated daily challenges.
* 📌 Ranking system and virtual rewards.
* 📌 Competition mode with friends.
* 📌 Anti-fraud mechanisms, including:
* Copy/Paste blocking.
   * Screen switching detection.
   * Penalties for suspicious behavior.

## 🛠️ Technologies Used

| Component | Technology |
|---|---|
| Frontend | Flutter or React Native |
| Backend | Node.js + Firebase / Django + PostgreSQL |
| Database | Firebase Firestore or PostgreSQL |
| Authentication | Firebase Authentication or Auth0 |
| AI | OpenAI API or Hugging Face |

## 🏗️ System Architecture
Mobile App (Flutter/React Native) -> Backend API (Node.js/Django) -> Database (Firestore/PostgreSQL) + AI Module (OpenAI/Hugging Face)

# 📚 Projeto GeniUs

## 📌 Visão Geral

**geniUs** é um aplicativo de estudos gamificado que utiliza Inteligência Artificial para criar desafios diários personalizados e promove competições entre alunos universitários. O objetivo é aumentar o engajamento nos estudos de forma interativa e divertida.

## 🎯 Objetivos
- **Personalizar o aprendizado** com IA.
- **Criar competições saudáveis** entre estudantes.
- **Utilizar gamificação** para incentivar a rotina de estudos.
- **Garantir um ambiente justo**, prevenindo fraudes.

## 🎯 Público-Alvo
Estudantes universitários que desejam melhorar seu desempenho acadêmico de maneira dinâmica e motivadora.

## 🚀 Funcionalidades
- 📌 **Cadastro e login** de usuários.
- 📌 **Seleção de disciplinas** para personalizar o aprendizado.
- 📌 **Desafios diários gerados por IA.**
- 📌 **Sistema de ranking e recompensas virtuais.**
- 📌 **Modo de competição com amigos.**
- 📌 **Mecanismos antifraude**, incluindo:
  - Bloqueio de copiar/colar.
  - Detecção de troca de tela.
  - Penalizações por comportamento suspeito.

## 🛠️ Tecnologias Utilizadas
| Componente | Tecnologia |
|------------|------------|
| **Frontend** | Flutter ou React Native |
| **Backend** | Node.js + Firebase / Django + PostgreSQL |
| **Banco de Dados** | Firebase Firestore ou PostgreSQL |
| **Autenticação** | Firebase Authentication ou Auth0 |
| **IA** | OpenAI API ou Hugging Face |
